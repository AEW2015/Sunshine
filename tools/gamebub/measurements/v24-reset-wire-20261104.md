# Windows RS24 wire checkpoint — 2026-11-04

The Windows offline executable now parses and serializes the reset-control
syntax from MoonBub commit `4025d35593e8b71b9d9f5e4fb68d1e7a9ed29189`.
This is a byte-conformance checkpoint. It does not execute the peer's state
machine, negotiate a profile, reset a decoder or send packets to hardware.

## Contract and scope

RS24 controls are exactly 46 bytes: little-endian `<4sBBIQQ16s>` followed by
IEEE CRC32 over the first 42 bytes. The parser checks magic, version, kind,
epoch bounds, positive host nonce, and HELLO/bound-message field restrictions.
The profile tag is opaque at this layer; successfully parsing an unknown tag
does not authorize sending media. These controls are separate from AV v1's
48-byte header and its whole-packet CRC. Neither live MSV1 nor AV v1 changes.

The published profile tag `d7bf1a169b4f75ffd9b36a5429c4c94d` describes
CP23/JA23 with HC22/HA22/HD22, coded 720×480, active 720×405, a 49,152-byte
complete-body cap, and independent AR03 key/full-HUD refresh. It does not
describe a standard HEVC/AV1 payload or grant compatibility with the existing
v20 Windows encoder. No CP23 data sender has been enabled.

The pinned `experiments/python-game-recovery-v24-study/results.json` is
172,586 bytes, SHA256
`93f91047a7b2ae82e866ac35de54d673ca228fa7331ea3d39fc3a62699dec802`.
Its ten campaigns and three reboot handshakes contain 124 controls. The new
command reserializes every control byte-for-byte, including controls marked
lost, and checks rejection of 5,704 single-byte bit corruptions. Reading
delivery flags and terminal phases is not an ownership/state replay.

Seven native tests separately cover an independent Python struct/zlib oracle,
all kinds and legal scalar boundaries, opaque tags, every single-bit corruption
of that oracle, every truncated length, trailing data, invalid local fields,
and CRC-resealed invalid grammar. Two real-command Python tests check the
pinned artifact and fail-closed missing/changed provenance.

   Port the bounded host reset state machine and replay exact state transitions,
   not just wire bytes. Cover all eight single-control losses, repeated BUSY,

### Next performance experiment

The current `build_ns` combines canonical-bank hashing, conversion, transform,
quantization, reconstruction, entropy and integrity work. `validate_ns` combines
bank copies, inner validation, assembly and independent decode/render. Split
those stages before ranking optimizations; keep frame-level total timings to
show instrumentation overhead. Compare sequential runs with the same frame
range on an idle host, retaining golden-byte and reference-state checks.

Candidate changes for that measured experiment are frozen quantizer tables for
the declared scales, byte-chunk writing in `Bits::put`, and bounded frame-local
quantized-coefficient scratch reuse. Test all starting bit offsets and widths
against the scalar bit writer, including Rice escapes and zero padding. Keep
canonical-bank revalidation and independent candidate decoding: mutable bank
aliases and publication safety still require those checks. These are proposed
experiments; no speedup from them is claimed here.
